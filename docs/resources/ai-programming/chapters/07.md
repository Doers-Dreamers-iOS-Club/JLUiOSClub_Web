## 先准备一个能反复修改的项目

新建一个练习文件夹，让 Agent 在这个文件夹里工作。首轮从空目录开始；中途接着做时，可以下载对应的阶段版本。把整个版本目录复制到练习文件夹，保留其中的 `index.html`、`styles.css` 和 `game.js`，用桌面浏览器打开 `index.html`。

<a href="/ai-programming/space-shooter/space-shooter-versions.zip" download>下载《深空防线》六轮游戏源码</a>

每完成一轮，保留一份当时能运行的副本。不要把新一轮的 `game.js` 单独塞进旧版本：页面元素和样式可能已经跟着变化。下文提示词根据原资料整理，适合在自己的工作副本中跟做。

| 制作顺序 | 这一轮做什么 | 完成后应能观察到什么 |
| --- | --- | --- |
| [01 首版](#first) | 移动、开火、敌机、计分与重开 | 可以完整玩完一局 |
| [02 炮口与弹道](#muzzles) | 给双列子弹明确的出弹位置 | 新子弹从两个炮口飞出 |
| [03 Boss 战](#boss) | 出场、两阶段攻击、胜负结算 | 击毁第 10 架敌机后进入 Boss 战 |
| [04 暂停与恢复](#pause) | 冻结战斗，处理按键状态 | 恢复时正确响应仍按住的键 |
| [05 废弃矿场](#mine) | 岩石掩体、三波敌机和新 Boss | 飞船可穿过岩石，子弹会击碎岩石 |
| [06 轨道船坞](#dock) | 激光关卡、第三个 Boss、切关检查 | 在预警结束前躲开固定的危险列 |

工具准备见[安装与启动](/resources/ai-programming/reference/tools)。这里直接进入制作；需要回查时，再看[任务描述](/resources/ai-programming/chapters/02)、[调试与交接](/resources/ai-programming/chapters/04)、[Skill](/resources/ai-programming/chapters/05)和[浏览器操作](/resources/ai-programming/chapters/06)。

## 第一轮 · 先做出可以玩完的一局 {#first}

先确定一局游戏的闭环：玩家移动和开火，敌机从上方出现，击毁后加分，受击后扣生命，生命耗尽后结算，再从初始状态重开。第一版只做这条流程。

**交给 Agent 的任务：**

```text
在当前空目录制作桌面浏览器太空射击游戏《深空防线》。
使用 HTML、CSS、JavaScript 和简单图形，不安装依赖，打开 index.html 即可玩。

玩家用方向键或 WASD 移动，按住空格连射，飞船不能移出战场。
敌机从上方出现，击毁一架加 100 分；玩家初始 3 条命，受击扣 1 条命。
显示操作说明、分数与生命。生命耗尽后显示最终得分，按 Enter 可重开。

请先实现移动与开火，再接入敌机、碰撞、计分、结算和重开。
同一架敌机只能计分或造成碰撞伤害一次。
重开时清空敌机、子弹和分数，恢复 3 条命；连续重开不能让游戏加速。
交付运行入口、关键文件说明和实际验证过的结果。
```

**制作时按三步推进。** 先打开页面试四向移动，确认飞船不会离开边界；接着按住空格，看子弹是否稳定发出、能否击毁敌机；最后主动受击，走完失败和重开。前一步没跑通，就把具体操作和现象反馈给 Agent，修好后再接下一步。

**完成这一轮前，实际试一次：** 击毁一架敌机看分数；让同一架敌机撞上飞船看扣命；用完生命进入结算，再连续重开两次。每次都应回到 0 分、3 条命，旧敌机和子弹被清空，生成速度保持正常。保存为「01 首版」。

## 第二轮 · 让炮口与弹道对齐 {#muzzles}

从首版继续。这里已经有向上的双列弹道，需要在机头画出两个炮口，并让新子弹使用这两个位置生成。

**先让 Agent 说明坐标怎么共用，再修改。** 飞船绘制和子弹生成都要读取同一组炮口位置。若两处分别写一套偏移量，静止时可能看着接近，移动或修改机身以后却容易错开。

```text
在首版上添加左右两个可见炮口，保留现有移动、长按空格和双列弹道。
左右子弹分别从对应炮口朝机头前方发射。
横移时，炮口与新子弹出生点必须跟随飞船一起移动。

请说明如何共用炮口坐标，再实施。完成后检查：原地连射、左移连射、
右移连射，以及结算重开后的第一次开火。把结果保存为第二版。
```

  <img src="/ai-programming/space-shooter/02-muzzles.png" alt="第二版的机头有两个发光炮口，最近的一对子弹分别与左右炮口对齐" loading="lazy" width="1280" height="820" decoding="async" />

**验收要盯住“刚出现的子弹”。** 原地按住空格，然后分别向左、向右移动并持续开火。旧子弹继续沿原来的轨迹前进，不应被拖着横移。需要逐帧判断时，录一段短视频，对照子弹出生那一帧的炮口位置。最后重开，检查第一对新子弹仍然对齐，保存为「02 炮口与弹道」。

## 第三轮 · 把 Boss 战接入一局游戏 {#boss}

从第二版继续。先决定什么时候出现 Boss、攻击如何提醒玩家，以及打完后这一局如何结束。《深空防线》采用“击毁第 10 架普通敌机后进入 Boss 战，击败 Boss 即本局胜利”的规则。

| 环节 | 要实现的行为 | 怎么检查 |
| --- | --- | --- |
| 出场 | 第 10 次击毁后停止生成普通敌机，预告后只出现一个 Boss | 从 9 架打到 10 架，看预告和独立血条 |
| 第一阶段 | 先提示危险方向，再发射扇形弹 | 看见预警后移动，确认有躲避机会 |
| 半血换招 | 血量首次降到一半或以下时切换一次，增加锁定攻击 | 预警出现后离开原位置，看危险区是否留在原处 |
| 结算 | 击败 Boss 显示胜利，奖励只加一次；双方同帧归零判玩家失败 | 分别覆盖胜利、失败和同时归零的边界情况 |
| 重开 | 清空旧 Boss、敌机、子弹与预警，恢复开局状态 | 从胜利页和失败页分别重开 |

**制作分两次落地。** 先接通“普通敌机 → 预告 → Boss 入场 → 结算”，确认不会反复生成 Boss；再加入扇形弹、半血换招和锁定攻击。这样遇到问题时，可以明确是在流程衔接还是某个招式上出错。

<details>
<summary>展开本轮任务提示词</summary>

```text
在第二版上加入两阶段 Boss 战，保留双炮口、移动和长按空格开火。
击毁第 10 架普通敌机后停止刷新的普通敌机，显示来袭预告，随后出现一个 Boss 和独立血条。
第一阶段先显示危险方向，再发射扇形弹。
血量首次到一半或以下时只换阶段一次；第二阶段增加锁定攻击，
锁定后的攻击位置固定，让玩家可以离开危险区。

击败 Boss 后显示本局胜利，奖励只记一次。玩家先阵亡判失败，
同一帧双方归零也判失败。胜败都能重开，清空旧敌机、Boss、弹幕和预警，
恢复初始生命，分数和击毁数归零。

先说明上述状态如何衔接，再分步实施。交付第三版和实际验收结果。
```

</details>

正常试玩至少走通一次出场与结算。半血阈值、奖励防重和同帧阵亡不容易靠一张截图证明，可以让 Agent 补充针对这些规则的检查，分别记录实际试玩与代码检查。保存为「03 Boss 战」。

## 第四轮 · 暂停后，接着刚才的操作 {#pause}

从第三版继续，加上 P 暂停和恢复，同时显示 Boss 预警剩余时间。暂停时，飞船、敌机、子弹和战斗计时都应停住；恢复后从原状态继续。

这轮曾出现一个具体问题：一直按住空格，按 P 暂停，再按 P 恢复，射击却停了；必须松开空格再按。调查发现，暂停操作清空了“当前按住哪些键”的记录。手还按着，游戏已经忘记了这个输入。

**先复现，再沿输入路径修复。** 让 Agent 找到按键按下、暂停、恢复、判断开火和松键的处理位置。暂停可以停止战斗更新，但已经按住的键不应无故丢失；暂停期间收到松键事件时，仍然要把相应的键从记录中移除。

```text
在第三版添加 P 暂停与恢复，显示 Boss 预警剩余时间。
暂停时冻结移动、射击、敌机、弹幕和预警倒计时。

按住空格或方向键，暂停再恢复，全程未松手时应继续响应；
暂停期间已经松开的键，恢复后不能继续生效。
请先检查按键记录与战斗更新的关系，解释准备修改的地方，再实现并逐项试玩。
单独说明：暂停期间才新按下的键，恢复时怎样处理。
```

**再测三种时序，不能只试一次暂停。**

| 操作顺序 | 恢复时要观察什么 | 资料包第四版的状态 |
| --- | --- | --- |
| 暂停前按住右键，全程不松手 | 是否立即继续右移 | 实测会继续移动 |
| 暂停期间才按住右键，恢复时仍按着 | 是否承认新按下的键 | 实测仍停在原地，需要松开重按 |
| 暂停期间松开右键，再恢复 | 是否停止移动 | 应停止；需在自己的版本验证松键路径 |

<figure>
  <img src="/ai-programming/space-shooter/04-new-key.png" alt="暂停期间才按下右键的对照，恢复后飞船仍停在中央附近" loading="lazy" width="1280" height="820" decoding="async" />
  <figcaption>对照组：暂停后才按住右键。第四版恢复后仍留在原处，因为暂停分支没有登记新按键。这是阶段版本的已知限制。</figcaption>
</figure>

如果你希望“恢复时所有仍按住的键都立即生效”，就继续要求 Agent 在暂停期间维护按下和松开的记录，只冻结战斗更新。改完重测表中的三组，再对空格执行同样的检查；最后在 Boss 预警中暂停，确认倒计时不会偷偷结束。保留这一轮结果与未完成项，再进入关卡制作。

## 第五轮 · 做一个玩法不同的「废弃矿场」 {#mine}

从第四版继续。第二关的变化是可破坏的岩石掩体：**飞船能穿过，子弹会被挡住，小岩石一发碎，大岩石两发碎。** 先把这组碰撞规则说清楚，再让 Agent 加波次和新敌人。

**先做入口和重置。** 顶栏增加 `01 / 02` 切关，第二关从 0 分、3 条命开始。切关立即重开选中的关卡，旧弹幕和 Boss 不带过去。第二关失败后，从自己的第一波重开。

**再做场景和碰撞。** 摆放大小岩石，给飞船的出生区留出空间。分别处理飞船经过岩石、玩家子弹命中岩石和敌方子弹命中岩石。岩石只影响子弹，不造成飞船接触伤害，也不计入敌机击毁配额。

**最后接上波次与 Boss。** 三波敌机的击毁配额分别为 8、10、12；达到本波配额并清空场上敌机后才进入下一波。第二、三波加入远程敌机 Sapper，第三波结束后进入两阶段 Boss「矿脉钻机」战。它的后半场会震碎剩余岩石，迫使玩家从借掩体躲避转为在开阔地移动。

<details>
<summary>展开第二关制作任务</summary>

```text
在第四版上添加独立第二关「废弃矿场」，保留第一关所有原有规则。
先增加 01/02 切关和关卡重置，再实现岩石碰撞，最后接入波次与 Boss。

切关立即从 0 分、3 条命重开；死亡回到本关第一波，清空旧敌机、弹幕与预警。
岩石只挡子弹，不挡飞船、不造成接触伤害；小岩石 1 发碎，大岩石 2 发碎。
玩家打碎岩石得 10 分，岩石不计入击毁配额。
三波配额 8/10/12，配额达成且场上敌机清空才进下一波。
第二、三波加入远程敌机 Sapper，其子弹也会被岩石挡住。
三波结束后进入两阶段「矿脉钻机」Boss 战；半血后震碎剩余岩石，核心暴露。

先列出第二关的敌人、攻击与碰撞规则，再实施。
每一步检查后回到第一关，确认第 10 架敌机触发 Boss、胜负与重开仍正常。
```

</details>

试玩时再检查大岩石需要两次命中、敌方子弹被岩石挡住、波次正确推进，以及切回第一关后规则保持正常。资料包第五版通过了 28 项 Node 检查，但当时完整的 Safari 手感验收仍待补；自己的版本仍要实际走完这些操作。保存为「05 废弃矿场」。

## 第六轮 · 用激光做出「轨道船坞」 {#dock}

从第五版继续。第三关沿用飞船操作、波次推进和胜负结算，把核心威胁换成固定纵列的激光：先标出危险位置，再发射，玩家可以在预警结束前横移离开。

**先写下本关的具体规则。** 第三关只保留普通冲锋敌机 Charger，三波配额为 10、12、14；没有岩石和 Sapper，第二、三波才出现关卡激光。Boss「环轨母舰」有 3000 血，第一阶段使用扇形弹，1500 血时进入第二阶段，扇射之外再加入激光。

**实现激光时，把预警与伤害分开。** 激光生成时记录玩家所在的横坐标，危险列随后保持固定。预警阶段只提示，发射阶段才判断伤害；激光结束、切关和重开都要清理旧状态。暂停时，预警和持续时间应一起冻结。

```text
在第五版上制作独立第三关「轨道船坞」，沿用已有波次、移动、双炮、暂停与结算。
增加顶栏 03 入口，切关与重开都清空旧关卡状态。

本关只生成 Charger，三波击毁配额为 10/12/14，没有岩石和 Sapper。
第二、三波增加竖直激光：生成时锁定玩家当时的横坐标，预警期间不造成伤害，
位置固定，玩家可以横移躲开；预警结束才发射，结束后清除。
Boss 为「环轨母舰」，3000 血，第一阶段扇射，1500 血时只转阶段一次，
第二阶段保留扇射并增加激光。击败后显示本关胜利。

先确认激光预警时长、持续时长和出现间隔，再实施。
回归第一关的 Boss 流程与第二关的岩石、波次和 Sapper，记录实际检查结果。
```
