## 项目与协作

- [第一章：先让一个想法动起来](/resources/ai-programming/chapters/01)：沿贪吃蛇完成描述、生成与试玩，起点参考 Datawhale Easy-Vibe。

- [计时与暂停](/resources/ai-programming/reference/glossary#timer)：对应第三章的精确修改。
- [保存版本与恢复](/resources/ai-programming/reference/glossary#git)：恢复前，确认当前差异与要保留的内容。

- [技能说明与例子](/resources/ai-programming/reference/glossary#skills)：认识技能的发现、读取与执行。

## 模型接入与 API

- [DSH 接入说明](/resources/ai-programming/chapters/api-setup)：先用界面完成连接，再认字段。
- [DeepSeek Harness 官网](https://www.deepseek.com/harness/)：下载桌面端。
- [DeepSeek API 控制台](https://platform.deepseek.com/)：创建密钥、查看用量与余额。
- [DeepSeek 首次调用](https://api-docs.deepseek.com/zh-cn/)：查地址、模型与认证方式。
- [DeepSeek 错误码](https://api-docs.deepseek.com/zh-cn/quick_start/error_codes/)：按状态码定位问题。
- [Python 调用选读](/resources/ai-programming/reference/python-api)：想自己编写调用程序时再继续。
- [DeepSeek 思考模式](https://api-docs.deepseek.com/zh-cn/guides/thinking_mode/)与[接口参数](https://api-docs.deepseek.com/api/create-chat-completion/)：配合 Python 示例查参数。
