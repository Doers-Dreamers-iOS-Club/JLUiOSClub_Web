# AI 编程入门专题设计

用户已批准专题导读、分章阅读、随查与下载方案，并要求博客式内容交互与动态图。现有工作区主题修改是实现依据，不覆盖或提交既有改动。

## 内容与信息架构

路径为 `/resources/ai-programming/`，包括首页、六章主线、API 补充、五篇随查、材料中心和连续阅读。以分章正文片段为唯一在线正文来源；连续阅读通过 include 组合。保留原文、出处、代码、问题和导航语义，重写站内链接。源码/配置既可预览也可下载；完整原始讲义包保持原目录。

## 博客式视觉

复用网站白底、衬线刊头、蓝色强调与细分隔线。首页采用刊头、原创 SVG 封面、编辑导语、两列章节目录、补充教程、随查与资料、相关阅读。正文页显示系列标识、学习目标、阅读时长估算、目录与上一章/下一章。插图使用语义明确的 SVG，颜色由主题令牌控制。

## 内容交互

- 第一/三章：SnakeLab，环形路径上的贪吃蛇计时示意，选择速度、开始/暂停、单步、重置；明确其为示意而非完整游戏。
- 第二章：PromptWorkshop，六轮对话逐步切换，显示任务、示例提示词和本轮检查目标，可复制。
- 第四/五/六章及 API 补充：FlowExplorer，配置化流程图，选择节点、单步、播放/暂停、重置，解释当前节点及信息流；自动播放仅经用户操作启动，离屏/切页停止，减弱动态效果使用手动模式。
- 每章小题：选择后给出解释，可重试；题目与正文结论一致。
- 阅读工具：显式标记已读，本机保存；首页显示六章阅读进度和继续阅读入口；存储不可用时不影响阅读。
- 交互组件 SSR 初始可读，键盘可操作，有可访问名称；移动端无页面水平溢出，暗色模式可读。
