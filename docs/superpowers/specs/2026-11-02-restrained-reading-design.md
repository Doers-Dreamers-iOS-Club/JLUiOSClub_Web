# 克制阅读型设计

用户已确认采用克制阅读型。改造前快照为 `1cea991`，实现分支为 `design/restrained-reading`。

后续参考：用户提供 Format Bureau 页面 https://s7zj4ixuvbxfi.ok.kimi.link/ 。借鉴错落网格、细分隔线、整行显现、列表轻横移与缓出节奏；首页展示标题调整为 36–60px，阅读页维持 22/18/16px。保留白灰蓝，不引入参考页的暖色、噪点、模糊与玻璃效果。首页入场约 0.7 秒，滚动进入约 0.55 秒，均为 transform / opacity。

保留现有白、灰、蓝及暗色配色值、内容路由和教学交互功能。统一系统无衬线字体，代码保留等宽；只使用 400、500 字重，标题 22/18/16px，正文 16px，辅助文字 13/14px。Anthropic Sans 未授权安装，不引入远程字体。

首页直接呈现社团介绍、两个主要行动、学习入口、活动记录与简短社团介绍。取消全屏 ASCII 及光标波纹，入口卡片仅保留标题、一句摘要和轻量类别信息。内页采用一致的标题、12px 圆角和细描边，删除纸角、阴影、模糊、装饰纹理与夸张动画。保留现有教学示意图和活动照片，不新增装饰图片。

GSAP 只在首页与栏目入口执行 6px 位移和短淡入，错开不超过 0.16 秒；正文始终可读，不逐段隐藏。路由立即响应，不等待离场动画；进入时轻微淡入，切换及卸载释放动画。运行时跟随减少动态效果偏好。

交互演示采用统一字体、平整背景、简短标签；把使用提示收进原生 details，保留状态反馈、键盘操作与核心功能。导航、搜索、深浅主题、归档视图切换、课程进度、测验和下载均保留。

验证：生产构建；桌面和 320/390px 移动端、深浅模式截图；首屏可见、无横向溢出、普通/修饰键链接、返回导航、减少动态效果及 JavaScript 关闭下阅读；运行既有课程交互回归脚本。
