# 活动总览页规范

适用于 `/activities/`、`/activities/260209-winter-swift/` 及后续活动总览页。具体讲义、记录正文仍为内容页，保留其侧栏。

- 使用 AI 编程总览页的杂志语言：整屏封页、大字中英排版、白底（兼容深色）、蓝色强调、细线、留白，减少解释性小字。
- 封页与正文采用已有双页面切换。下拉进入正文，上滑到正文顶端返回封页；动画可中断，不等待插图播完。矮屏与无 JavaScript 时原生滚动。
- 正文先呈现该页专属 SVG 动画概览，再进入可点击目录；不重复放两套完整目录。
- 两个总览页均无左右侧栏。活动索引按年份自动收集现有全部活动，保留更早活动名称及 AI 编程入口。冬季 Swift 保留两讲、AI 补充讲座、视频、GitHub、Gitee 入口。
- SVG 不统一成三段式：活动索引为展开的活动编辑台，将相聚、代码与设备体验连接成整体；冬季 Swift 围绕 CodeBreaker 的界面、棋子与匹配反馈单独构图。图示均使用原生 SVG，不使用 ASCII 或下载大图。
- 提供可复用 ActivityOverview 封页/正文外壳，页面通过插槽注入独立插图与目录。封页动效可配置，保留 AI 编程页原有液面动画。新增总览页复用结构而非复用同一张插图。
- 动效只在可见区域播放，切页、切路由和离屏时正确清理/暂停，支持减少动态效果、键盘、触摸和锚点。
- 每页完成并验证后分别 commit。本地预览交用户检查，通过后才 push。

实施顺序：共享外壳和活动索引 → 构建/浏览器检查/首个 commit → 冬季 Swift 独立 SVG 与目录 → 构建/两页导航与原课程回归/第二个 commit → 打开两个本地页面。验收覆盖链接完整性、侧栏边界、全屏尺寸、双向切页、非阻塞 SVG、320/390px 与深色/减少动态效果。
