# AI 编程入门：杂志式专题页

## 目标与范围

重排 `/resources/ai-programming/`，保留简约杂志的标题层级、留白与编辑节奏。与主页沿用黑白灰、蓝色、细线及本地衬线字体。用户明确要求不用 ASCII 风格；后续要求保留英文大字与现有主视觉，在其下加入原来的「想法 → 代码 → 贪吃蛇」SVG，并大幅删减说明文字。

## 最终版式

- 封面保留双栏中文标题与 Instrument Serif「Hello, world.」，铺满导航栏下方的整个首屏。中文标题弱化「从 / 到」，「想法」用衬线字体，「作品」用蓝色无衬线字体，第二行轻微错位。
- 第一章入口扩大为桌面 20px 字号、300px 宽、至少 68px 高，手机保持至少 54px 点击高度。保留工具准备和连续阅读，底部仅增加向下箭头。
- 删除封面导读、装饰性英文副标题、读者说明、课程数量、作品数量和阅读进度区。
- 封面下新增精绘的三段 SVG：草稿纸与铅笔、代码窗口、完成的贪吃蛇游戏。只保留「想法 / 代码 / 作品」标签，用连线表达过程。
- 课程目录仅保留六章编号、标题和链接，删除摘要、分类与英文栏目编号。
- 延伸教程用模型接入与终端代码插图；延伸学习用模型关系、App 创作、Agent 操作插图，均不附说明段落。
- 参考、材料、继续探索使用直接简短的栏目名。全部 18 个独立目标地址及下载功能保留。
- 手机按单栏排列三段主图，保持图形可读；深色主题沿用现有颜色变量。

## 实现边界

`CourseLanding.vue` 由本页 Markdown 导入。`CourseArtwork.vue` 保留原三段叙事并重新绘制，`CourseSpot.vue` 提供五幅轻量主题插图。所有 SVG 服务端渲染，不增加外部图片、Canvas 或依赖。仍使用现有约 15 KB 本地字体。

阅读进度仅从入口页移除，章节页的已读标记及本地保存继续有效。现有回归检查改为回到章节验证保存的已读状态。

## 滚动与插图动效

- 封面与正文采用两个独立页面状态。当前页面进入正常文档布局，另一页绝对定位并隐藏、设为 inert；不把封面高度计入正文滚动。
- 正文滚动位置从零开始。正常向上滚到零时返回封面；已经在正文顶部时，继续上滑触发返回。不推算高度差，不提前跳页。
- 在整个视口监听手势，正文与两侧留白行为一致；搜索、导航菜单、输入和嵌套滚动区域保持正常操作。反方向手势可立即开始新一轮切换。
- 使用与主页一致的双层反向位移揭幕：桌面 0.85 秒、手机 0.62 秒。切入正文后，同一手势的后续向下滚动立即交还浏览器，不等待 SVG 动画播完。
- 内容状态用 `#course-content` 保存，支持直接链接和历史返回。减少动态效果时立即切换，低高度窗口退回普通长页；无 JavaScript 时封面、正文与锚点完整可用。
- 开屏用细线展开、中文行遮罩上移、Hello/world 逐字翻入、world 细描边渐渐填实、星号旋转和入口错峰显现。初次访问、跨页进入和从正文返回统一播放，结束后清理临时样式。
- world 使用固定波浪遮罩表现液体从底部注入，每个字母填充 2 秒并略微错峰，液面左右晃动逐渐减弱。遮罩和文字反向位移，保持文字与描边对齐；避免逐帧改变描边、填色或 SVG 路径。装满后移除遮罩与临时合成层提示，减少动态效果时直接显示完整文字。顶部细线单独做 transform 动画，避免根节点自定义属性逐帧传播。
- 正文保持 0.65 秒（手机 0.4 秒）的轻微滚动跟随。页面切换完成后刷新位置测量。
- 三幅主图按顺序短播：草稿描线、代码逐行显示、播放按钮轻按、贪吃蛇绘成。封面后面的隐藏插图不播放；手机每幅图进入视口才开始，离屏或后台暂停，完成后静止。
- `useCourseCover.ts` 管理页面状态和封面动效；`useCourseArtworkMotion.ts` 管理插图；`useCourseScrollMotion.ts` 管理正文滚动。

构建全站，检查 1440、1024、768、640、390、320 像素视口、深色模式、关闭 JavaScript 时的图文、18 个原目标地址与下载；运行课程交互回归。截图检查后保持最新本地预览，提交本地 commit，不推送。

动效检查：`node scripts/check-course-motion.mjs http://localhost:4174`，覆盖实际滚动跟随、桌面流程、手机独立触发、离屏/后台暂停、实时减少动态效果、键盘导航、卸载清理和关闭 JavaScript。

封面检查：`node scripts/check-course-cover.mjs http://localhost:4174`，覆盖首屏尺寸、滚轮惯性锁定、反向切换、正文自由滚动、键盘、真实触摸、减少动态效果、低高度降级及无 JavaScript 锚点。
