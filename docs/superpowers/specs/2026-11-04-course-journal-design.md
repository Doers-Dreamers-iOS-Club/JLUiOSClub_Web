# AI 编程入门：杂志式专题页

## 目标与范围

重排 `/resources/ai-programming/`，让入口页具备简约杂志的标题层级、留白与编辑节奏。用户明确要求不用 ASCII 风格。与主页的视觉联系来自同一套黑白灰、蓝色、细线和本地衬线字体，不复制主页的图形与动画。

## 版式

- 封面：双栏，左侧「从想法 / 到作品。」与导读，右侧 Instrument Serif 排印「Hello, / world.」。小字号刊头与页脚标明课程、读者、章节与项目数量。
- 阅读进度：沿用本地存储与继续阅读逻辑，呈现为细线进度带。
- 课程目录：六行单栏编号目录，展示已有章节标题、摘要与分类；所有原链接保留。
- 延伸教程：两个无外框分栏，清楚标注补充教程与 Python 选读。
- 参考与材料：参考索引与下载侧栏并排。
- 延伸学习：三栏文章推荐，保留原活动链接。
- 手机改为单栏，英文封面收成横排，章节分类移入正文下方；深色主题沿用已有颜色变量。

## 实现边界

独立 `CourseLanding.vue` 由本页 Markdown 导入，不注册到全局。`CourseProgress.vue` 仅新增可选 editorial 版式，默认样式及数据逻辑不变。字体继续使用已有约 15 KB 本地 WOFF2；不增加图片、Canvas、计时器或依赖。入口沿用已有页面淡入与路由过渡；链接仅有短距离箭头反馈，减少动态效果时关闭位移。

## 验证

构建完整站点；浏览器检查 1440、768、390、320 像素视口、深色模式、无 JavaScript 的服务端内容、全部原始入口与讲义下载、阅读进度恢复及章节导航。视觉检查截图后启动最新本地预览，提交本地 commit，不推送。
