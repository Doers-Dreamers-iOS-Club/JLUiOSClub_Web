# 网页维护指南与动画展示

用户要求将动画展示、内容组件、模板和维护说明打包为“网页维护指南”，放在“关于我们”模块下；承接已确认的动画预览、复用代码与参数说明方案。

## 信息组织

```text
/about-us/maintenance/
+-- index.md        # 入口与模板下载
+-- components.md   # 已有内容组件指南
+-- animations.md   # 动画展示与复用
+-- development.md  # 开发、内容维护与扩展约定
```

顶部入口放在“关于我们”，四个页面共用侧栏。原组件指南为本分支中新建、尚未发布的页面，移动到新目录后更新源码和测试中的链接。

## 动画展示

集中登记 14 个示例：10 个教学场景、课程三阶段插画、活动编辑台、SwiftUI 插画、链接翻动文字。展示页只挂载当前选择的动画，支持选择、重播、复制代码；异步组件定义放在模块目录中，复用原组件与播放生命周期。按用户补充要求保留常用插画预加载，并在默认示例资源就绪后顺序预热剩余小动画；选择框聚焦或悬停提前启动。预加载只下载和初始化模块，不挂载隐藏动画，不预加载首页 WebGL。

全局组件直接给出标签，局部组件给出 `@theme` 导入和标签。说明播放规则、可调参数与多实例行为。首页 ASCII 与整屏转场、活动/课程封面、导航搜索等依赖页面结构的效果链接至原页面体验，不在展示页嵌套整页。

活动插画改用 Vue useId 生成无障碍标识，字体和 SSR 动画起点不再依赖活动页容器，保证普通 Markdown 中的独立使用。原有编排与时长保持不变。
